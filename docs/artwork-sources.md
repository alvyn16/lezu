# Prototype artwork and fixture facts

This rebuild contains no code or configuration imported from the previous Lezu project. Original artwork was obtained independently for this local visual review. Copyright and trademarks remain with their respective owners; these are not Lezu-owned assets.

| Files | Source |
|---|---|
| `alan-hero.webp`, `alan-logo.png`, `alan-cover.png`, `alan-screen.png` | [Official Alan Wake website](https://www.alanwake.com/), using its linked key art, horizontal logo, standard artwork, and launch screenshot. |
| `sifu-hero.jpg`, `sifu-cover.jpg`, `sifu-logo.png`, `sifu-screen-*.jpg` | [Official Sifu Steam store](https://store.steampowered.com/app/2138710/Sifu/), Valve's artwork CDN and app-details API. |
| `witcher-*`, `hearts-*`, `elden-*`, `balatro-*`, `devil-*` | Read-only copies from the independent local Steam library-art cache, app IDs 292030, 394360, 1245620, 2379780, and 601150 respectively. No installed-game data was imported. |
| `steam.svg`, `epic.svg`, `gog.svg` | [Simple Icons](https://github.com/simple-icons/simple-icons), `steam`, `epicgames`, and `gogdotcom` marks. |
| `docs/references/*.png` | User-supplied design references, copied with no alteration. |

Sifu's original release year is 2022, from [Sloclap's launch announcement](https://www.sifugame.com/news/sifu-is-available-now). The reference shows 2023; that is the later Steam release year. This Epic fixture uses the original release year. Developer and descriptive content were checked against the official game pages. The descriptions are short original paraphrases.

Source assignments, installation flags, playtime, and last-played values are explicitly sample data. Storage sizes, ratings, and other unknown fields are not invented. Third-party artwork stays local to this review candidate; no release or asset publication was performed.
